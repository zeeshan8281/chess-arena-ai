## Governance

Sixteen approved source families, seventeen URLs (Proxy War homepage/build count as one family). Fourteen official families: **87.5% official**. Domains include softmax.com, proxywar.xyz, github.com, pwang724.github.io, huggingface.co, arxiv.org, battlecode.au, chess.com and lichess.org. Even combining GitHub Pages with GitHub yields **eight domain groups**. Different repositories on GitHub are different primary publishers, not independent host domains. No key claim should depend on more than 25% of this set's narrative weight from one source. Do not pad citations to manufacture independent corroboration.

Sources 1–5 have browser-primary priority because they address the user's newly clarified harness-improvement direction. Source 15 is historical and supports reusable analysis artifacts only, not current UI or endpoint contracts. Research papers support method distinctions; their model rankings are not current claims about this arena. Mutable repositories were not pinned in this review. Exact access date is supplied above and must not be invented as a publication date.

Authority describes usefulness for narrow attributed claims, not proof of product adoption, security or replication. Proposals and locally inspected capabilities must be labeled separately from external observations.
