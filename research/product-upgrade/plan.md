# Product improvement research plan
AS_OF: 2026-10-13. General Research, Standard depth. Purpose: choose and implement useful, professional additions to the live chess-agent website. Deliver a 3,000–5,000 word research/decision report as repository documentation, not a long user-facing essay. No invented rankings, fabricated community activity, or proposal forms as onboarding.

Capabilities: web search/fetch, writable filesystem, research subagents available. Public third-party sources only. Current app inspection is implementation evidence, not external market validation.

Group A, three parallel tasks (DEEP):
A. Agent-product onboarding: Softmax, Kaggle environments and comparable developer competitions. Queries: Softmax play onboarding; Kaggle game agents getting started; agent arena replay improve workflow. Output notes/task-a.md.
B. Chess learning and spectator products: Lichess studies/puzzles/analysis, Chess.com game review. Queries: Lichess study analysis puzzles official; Chess.com game review key moments. Output notes/task-b.md.
C. Evaluation trust and professional presentation: DeepMind Game Arena, Hugging Face leaderboards, benchmark methodology. Queries: Game Arena evaluation methodology; Hugging Face leaderboard limitations; chess language model benchmark reproducibility. Output notes/task-c.md.

Group B, after Group A (DEEP/analysis):
D. Concrete candidate content/features and data licensing, with implementation boundaries. Output notes/task-d.md.
E. Evidence-mapped product prioritization and complete independent draft one. Output notes/task-e.md and draft-one.md.
F. Counter-position, professional information architecture and complete independent draft two. Output notes/task-f.md and draft-two.md.

Sources: >=12 approved URLs, >=5 domains, >=30% official. Every source tagged type, public accessibility, date/access date, authority. Max 25% key claims attributed to one source. Distinguish observations from recommendations and feasibility; no customer-demand claims without evidence.

Counter-review: test whether additions distract from the core play/watch/improve loop; whether tiny samples, legal-move assistance or seeded fixtures are misrepresented as scientific results; whether copied competitor patterns actually imply product success; whether content is actionable without accounts or paid APIs.
